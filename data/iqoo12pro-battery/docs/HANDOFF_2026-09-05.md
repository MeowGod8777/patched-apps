## Product goal

Build a low-interference, long-term natural-usage battery ledger for iQOO 12 Pro / V2329A that supports reliable comparisons across:

- home Wi-Fi vs mobile / mixed / other-Wi-Fi use when context evidence exists
- navigation vs non-navigation
- app/workload composition
- battery aging
- OriginOS / resolution / refresh / root / scheduler / other configuration changes

This is not a fixed workload benchmark and sessions do not need to be 100% -> 0%.

- session average power uses `avg(current * voltage)` only over valid screen-on discharge/not-charging samples
- theoretical runtime is workload-normalized; core implementation is approximately `batteryEnergy / abs(avgPower) × 0.9`

## Canonical semantic definitions

For the current Scene lineage:

- `history_session_at` = History row start timestamp = `beginTime`
- `history_time_semantics = start`
- `screen_on_duration_seconds` = Scene-valid screen-on sampled time
- `screen_on_semantics = scene_valid_screen_on_samples_3s`
- `wall_duration_seconds` = History second duration = `endTime - beginTime`
- `interval_start = history_session_at`
- `interval_end = interval_start + wall_duration` when wall duration was actually captured
- `avg_power_w` = screen-on workload-normalized average device power
- `theoretical_runtime_seconds` = Scene theoretical-runtime estimate, separate from History wall duration

Older 41-session captures did not preserve History-list wall duration in the current ledger. Leave historical wall duration/end time blank rather than substituting theoretical runtime or guessing.
